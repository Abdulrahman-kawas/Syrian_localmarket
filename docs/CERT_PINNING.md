# Certificate Pinning (Mobile)

The mobile app pins the API's TLS public key so a man-in-the-middle with a
rogue-but-valid certificate cannot intercept traffic. Pinning is configured
declaratively and **takes effect in release / dev-client builds only** — it does
**not** apply in Expo Go.

- **iOS:** `NSAppTransportSecurity → NSPinnedDomains` in `app.config.ts`
  (`ios.infoPlist`). Native, no code.
- **Android:** a `network_security_config.xml` `<pin-set>` generated by the local
  config plugin [`plugins/withAndroidCertPinning.js`](../mobile/plugins/withAndroidCertPinning.js),
  wired into the manifest automatically at prebuild.

Both read the same host + pin values you set in `app.config.ts`.

## 1. Generate the SPKI SHA-256 pin

Pin the **public key** (SPKI), not the certificate — this survives certificate
renewal as long as the key is reused. Run against your API host:

```bash
openssl s_client -connect api.localmarket.app:443 -servername api.localmarket.app < /dev/null 2>/dev/null \
  | openssl x509 -pubkey -noout \
  | openssl pkey -pubin -outform der \
  | openssl dgst -sha256 -binary \
  | openssl enc -base64
```

The output (e.g. `k3XNEfQ…=`) is your pin.

## 2. Add it to `app.config.ts`

Replace `REPLACE_WITH_REAL_SPKI_PIN_BASE64=` in **both** the iOS
`NSPinnedCAIdentities` entry and the Android plugin `pins` array.

**Always include a backup pin** (your next key / intermediate CA) so a key
rotation doesn't brick installed apps:

```ts
pins: ['<primary-spki-pin>=', '<backup-spki-pin>='];
```

## 3. Build

Pinning is applied by a native build:

```bash
cd mobile
npx expo prebuild          # runs the config plugins
npx expo run:android       # or run:ios / an EAS build
```

## 4. Rotate safely

1. Add the new key's pin as an **additional** entry (keep the old one).
2. Ship the app; wait for adoption.
3. Rotate the server certificate to the new key.
4. Remove the old pin in a later release.

> If you ever need to disable pinning for debugging, remove the plugin entry and
> the `NSPinnedDomains` block, then re-prebuild.
